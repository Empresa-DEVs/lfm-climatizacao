# LFM Climatização — Landing page (React + Vite + TypeScript)

    npm install
    npm run dev      # desenvolvimento
    npm run build    # gera a pasta dist/ para publicar

## Onde editar
- `src/data/content.ts`: textos, WhatsApp, Instagram, posts, galeria.
- Galeria: preencha `src` em `GALLERY` com fotos/vídeos reais (coloque os arquivos em `src/assets/`).
- Instagram: `EMBED_INSTAGRAM = true` mostra os posts reais; adicione links em `IG_POSTS`.
- `src/data/art.ts`: ilustrações SVG (podem ser trocadas por fotos).
- `src/styles.css`: estilos e cores (variáveis no topo).
